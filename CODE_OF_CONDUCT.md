# Contributor Covenant Code of Conduct (v2.1)

## Our Pledge
We as contributors and maintainers pledge to make participation in this project a harassment-free experience for everyone.

## Our Standards
Examples of behavior that contributes to a positive environment:
- Using welcoming, inclusive language.
- Showing respect for differing viewpoints.
- Gracefully accepting constructive feedback.
- Focusing on what is best for the community.

Unacceptable behavior includes:
- Intimidation, harassment, or discriminatory language/actions.
- Personal insults or attacks.
- Sustained disruption of project work.

## Enforcement
Instances of abusive behavior can be reported by contacting the project maintainers at: vishish123@gmail.com. Reports will be handled confidentially.
